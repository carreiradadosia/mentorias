# mentorias

Material público da mentoria de engenharia de dados, mantido por Iuri Zambotto e Paulo Shindi.

## Estrutura

- `engenharia_de_dados/`: trilha, apostilas de módulo e README gerado a partir de `trilha.yml`.
- `experimentos/`: prompts, agentes e resultados de experimentos publicados em artigo.

## Como consumir

Cada módulo publicado tem README e apostila próprios em `engenharia_de_dados/modulos/<slug>/`.
A ordem sugerida de estudo está em `engenharia_de_dados/README.md`.
